# Color Picker Folders

A tiny, portable colour picker for Windows that saves picks into simple folders. No install, no ads, no sign-in.

**Download:** [latest release](https://github.com/DisorderedGhosts/color-picker-folders/releases/latest)

**Build from source:** run `build.bat`. It uses the C# compiler built into Windows and writes `bin\ColorPicker.exe`.
